# 2026-08-22/23 — Integration campaign, schema-guided refactor rounds, Claude-native adoption

## Database and integration truth

- First full real-PostgreSQL integration campaign since Docker/WSL2 became
  available on this machine. Five rounds took the suite from 46 failures to
  **312/312 green** (API 159, worker 153) against a disposable `postgres:17`
  container.
- Three append-only trigger-repair migrations landed, all fixing defects
  introduced in the 0047-0051 trigger program and invisible to unit tests:
  - `0052_fix_agent_run_workflow_identity.sql` — the run-level identity
    trigger referenced `NEW."output_ref"`, a column that exists only on
    `agent_run_steps`.
  - `0053_fix_agent_run_event_step_key.sql` — a PL/pgSQL variable named
    `step_key` collided with the selected column of the same name.
  - `0054_fix_jsonb_text_concatenation_precedence.sql` — unparenthesized
    `'prefix:' || jsonb->>'field'` expressions grouped as
    `(text || jsonb) ->> field`.
- Production fixes validated by the campaign: request-validation filter,
  queue-producer advisory lock with terminal-only archive, release media
  verification reading storage before `FOR UPDATE` (now pinned by a dedicated
  concurrency test), and ISO-`timestamptz` encoding for recovery liveness
  bounds in `work-recovery.ts` and `opportunity-research-execution.ts`.

## Schema-guided refactor rounds (nine cases, each adjudicated before commit)

- `classifyRankingProof` boolean flags -> honest `rank: number` (`0d98a4c`).

  (ADR 0021 + guard anchors; confirming existing code is a valid outcome).
- `buildReleasePreflightChecks` if-chain -> typed check table (`df5707c`).
- Local-page QA input -> discriminated union carrying registry-owned facts,
  proven identical across 12,289 input combinations (`3ea0939`).

  (`c5ffcd8`).

  `satisfies Record<OpportunityResearchFailureCode, string>` (`7b7b585`).
- Queue-job schemas -> shared `JobDataEnvelopeSchema`; the `.strict()` drift
  (Deploy/Rollback/WebsiteImport/OpportunityScout lax, six strict) is
  preserved and tracked as an open contract decision (`f6704f0`).
- Page-version tenancy join (10 hand-written copies) -> single owner
  `pageVersionProjectScope` in `packages/db`, banned per file by nine guard
  anchors (`1d75b21`).
- Deploy guard ladder duplicated with swapped middle branches -> one pure
  `decideProviderDeployAction` union; manual reconciliation now outranks a
  recorded `providerDeployId` per ADR 0009, closing a reachable path that
  auto-uploaded a manually stranded deployment (`63cc322`). Follow-ups in
  progress: replay-vs-manual precedence, API rollback queries missing the
  manual filter.
