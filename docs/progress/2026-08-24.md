## Regression caught by the integration gate

The first integration run failed one API case: `reviewPageVersion` on the new
`PagesService` facade delegated without `async`, so the synchronous throw from
`parseReviewPageVersionRequest` escaped as a synchronous exception instead of
the rejected promise the original `async` method produced. Fifteen sibling
methods are pure delegations where the shape is equivalent; this one performs
work before delegating, which is exactly what makes the difference observable.
Restored `async` with a comment naming the reason, so a later cleanup pass does
not "simplify" it back. Typecheck, lint, unit tests, and the guard script all
passed before this was found - only the real-database suite surfaced it.

## Docker recovery (host issue, no repository change)

Docker Desktop refused to start: unclean termination on 2026-08-22 left
zero-byte AF_UNIX socket reparse points that Windows will neither open nor
delete, and Docker aborts startup when it cannot remove its own stale socket.
Two directories were affected in sequence (`Docker/run`, then
`docker-secrets-engine`), the second only visible in
`com.docker.backend.exe.log`. Renaming both directories out of the way let
Docker recreate them; daemon ready in ten seconds.
