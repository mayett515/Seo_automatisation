# SEO domain package

This package is functional core unless a file is explicitly an adapter boundary.

- Follow the parent domain rules.
- SEO recommendations distinguish verified evidence, inference, and unknowns.
- Generated local pages must pass the project's content and page-quality gates before preview approval or deployment.
- No invented rankings, traffic, business facts, provider results, or customer claims.
- Planning and prioritization read the relevant product rule or ADR rather than encoding product policy in an infrastructure adapter.
